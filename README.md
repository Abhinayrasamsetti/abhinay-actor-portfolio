# Jagadeeswar Abhinay Rasamsetti — Actor Portfolio

A cinematic, responsive, static portfolio designed for GitHub Pages.

## Publish on GitHub Pages

1. Create a new GitHub repository, for example:
   `jagadeeswar-actor-portfolio`
2. Upload everything in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Save. GitHub will provide the Pages URL.

## Before publishing

Open `index.html` and replace:
- `YOUR_EMAIL@example.com`
- `YOUR_INSTAGRAM_URL`

## Add your videos later

The work section currently contains a showreel placeholder. You can replace that section with YouTube/Vimeo links once your clips are ready.

## Included assets

The `assets/images/` folder contains the three photographs supplied for this portfolio.
